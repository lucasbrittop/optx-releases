# optmzr

O optmzr é um otimizador leve para Windows 11, feito para jogos. Ele fica na bandeja do sistema, quase sem usar recursos, e cada ajuste pode ser desfeito. Aqui ficam as versões para baixar.

**Baixe o `optmzr-setup-<versão>.exe` da [última versão](https://github.com/lucasbrittop/optx-releases/releases/latest)** (parte Assets da página).

## Como instalar

1. Baixe o `optmzr-setup-<versão>.exe` pelo link acima e dê dois cliques.
2. **Apareceu "O Windows protegeu o computador"?** Clique em **Mais informações** e depois em **Executar assim mesmo**. Isso acontece porque o app ainda não tem assinatura digital.
3. **O antivírus reclamou?** É comum com otimizadores sem assinatura, porque o app mexe em configurações do Windows. Em **Segurança do Windows** → **Proteção contra vírus e ameaças** → **Histórico de proteção**, ache o optmzr e escolha **Restaurar** (ou **Permitir**). Se tiver dúvida, fale com o Lucas.
4. Na primeira instalação o PC precisa de internet, para baixar o componente .NET 8 da Microsoft, se ele não estiver instalado.
5. **Para atualizar:** abra o optmzr e vá em **Configurações** → **Buscar atualização**.
6. **Para desinstalar:** **Configurações do Windows** → **Aplicativos** → **optmzr**. Ele pergunta se você quer desfazer os ajustes.
